# PROYECTO1-PROG2-SISTEMA-DE-GESTION-HOSPITALARIA

Un sistema completo de gestión hospitalaria desarrollado en C++ que permite administrar pacientes, doctores, citas médicas e historiales clínicos.

Funcionalidades Principales

Gestión de Pacientes: Registro, búsqueda y listado de pacientes
Gestión de Doctores: Registro y administración de personal médico
Sistema de Citas: Agendamiento y verificación de disponibilidad
Historial Médico: Seguimiento completo de consultas y tratamientos
Memoria Dinámica: Gestión eficiente de recursos con arrays dinámicos

Tecnologías Utilizadas

Lenguaje: C++ (estándar C++11)
Bibliotecas: <iostream>, <cstring>, <iomanip>

Estructuras

Hospital: Estructura principal del sistema
Paciente: Datos personales y médicos del paciente
Doctor: Información profesional del médico
Cita: Gestión de citas médicas
HistorialMedico: Registro de consultas y tratamientos 

Funciones 

Gestión de memoria dinámica
Operaciones CRUD (Crear, Leer, Actualizar, Eliminar)
Validación de datos
Búsquedas y filtros

Menús

Interfaz de usuario intuitiva
Navegación entre módulos
Formato tabular para visualización de datos

Prerrequisitos

Compilador C++ compatible (GCC, Clang, MSVC)
Estándar C++11 o superior

Errores Comunes

Compilación: Asegurarse de usar C++11 o superior
Ejecución: Verificar permisos en el ejecutable
Entrada: Seguir formatos de fecha (YYYY-MM-DD) y hora (HH:MM)
